AADHAAR PRINTASSIST V5 - WINDOWS QUICK START

SOURCE PACKAGE (this ZIP)
1. Extract the complete ZIP to a permanent private local folder.
2. Install Python 3.11 or newer with Tcl/Tk and the Python launcher.
3. Double-click Create-Desktop-Shortcut.bat once. First setup installs
   dependencies and needs internet access. No administrator rights needed.
4. Open Aadhaar PrintAssist from the Desktop or Start menu.
   Normal launches use pythonw, so no terminal window stays open.
5. Keep the entire extracted folder in place. If you move it, run shortcut
   setup again. To remove shortcuts, delete them from Desktop/Start menu.

WINDOWS EXECUTABLE BUILD (for the shop's distributor/administrator)
Run build-windows.ps1 on Windows. It runs automated tests and builds
  dist\AadhaarPrintAssist\AadhaarPrintAssist.exe
with the app icon. Copy/distribute that ENTIRE AadhaarPrintAssist folder.
In that folder run Create-Desktop-Shortcut.bat. The EXE edition needs no
Python installation or dependency download on the receiving PC.
The build script needs internet for initial dependencies.

DAILY USE
Open the desktop icon, choose a PDF, enter customer name/DOB, confirm
customer authorization, unlock/verify, review preview, save or print.
Use bundled trust by default; customers provide no CA/evidence folder.
Exports use the entered name, replacing spaces with underscores.
An incomplete/invalid signature never becomes verified by checking an option.
The original upload is preserved; print copies do not keep its digital signature.
